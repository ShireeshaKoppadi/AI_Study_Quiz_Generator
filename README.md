# AI Study Quiz Generator

AI Study Quiz Generator is a web-based application that converts study material into interactive multiple-choice quizzes using Artificial Intelligence.

## About the Project

The AI Study Quiz Generator helps students prepare for exams by automatically generating quiz questions from their study material.

Users can enter or paste their study content into the application. The system processes the content using AI and generates multiple-choice questions with different answer options.

This makes learning more interactive and helps students test their knowledge quickly.

## Features

- AI-powered quiz generation
- Generate multiple-choice questions from study material
- User registration and login
- Interactive quiz interface
- Automatic quiz result calculation
- Score display
- Quiz history
- Leaderboard
- Simple and user-friendly interface
- Responsive web design
- PDF notes upload
- Difficulty selection
- Custom number of questions
